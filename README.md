# Mahesh — React Freelancer Portfolio

A responsive React + Vite portfolio for a SharePoint and web developer.

## Run locally
1. Install Node.js (LTS): https://nodejs.org/
2. Extract this ZIP and open the project folder in VS Code.
3. Open a terminal in the project folder and run:

```bash
npm install
npm run dev
```

4. Open the local URL printed by Vite (usually http://localhost:5173).

## Build for production

```bash
npm run build
npm run preview
```

The production site is generated in `dist/`.

## Before publishing
- Replace `YOUR_EMAIL@example.com` in `src/App.jsx` with your real professional email.
- Replace `YOUR-LINKEDIN` with your LinkedIn profile slug.
- Verify the skills and services; remove anything you cannot confidently deliver.
- Replace concept projects with real work samples, or keep them clearly labelled as demo concepts.
- Do not publish confidential employer/client information or unapproved screenshots.

## Free hosting
You can deploy the project on Vercel or Netlify. For static hosting, run `npm run build` and deploy the generated `dist` folder.
